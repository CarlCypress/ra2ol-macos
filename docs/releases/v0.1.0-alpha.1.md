首个 macOS 实验性预览版，适合在 Apple 芯片 Mac 上测试红警战网。

## 下载

- `ra2ol-macos-0.1.0-alpha.1-universal.zip`：预编译启动器、按键组件、安装工具和中文说明。
- `SHA256SUMS.txt`：上述 ZIP 的 SHA256 校验值。
- GitHub 自动生成的 Source code 压缩包供开发使用；首次安装优先下载 universal ZIP。

解压后阅读 `开始使用.md`，准备 Python 3.9+、Rosetta 2 和有权使用的中文字体，然后运行 `安装.command`。依赖仍需联网下载，不包含游戏、字体或完整 Wine 环境。已有 `~/RA2OLMac` 时请先只读检查，安装工具会拒绝覆盖。

## 包含的功能

- 通用 macOS 原生启动器与按键组件，支持强制结束本项目的战网和游戏。
- 独立 Wine / GStreamer 环境、固定版本与 SHA256 校验、Rosetta 修复模块提取。
- Command → Ctrl、实体 Control → Alt、Option → Alt。
- 中文字体注册、2304×1296 窗口设置及修改前备份。

## 验证与限制

- 原型机：MacBook Air M3、macOS 15.7.4。窗口尺寸已由使用者确认。
- 原先一两分钟后退出的 Wine 问题已通过同模式同地图超过 5 分钟的实测。
- 后续一次约 22 分钟对局在 `00505E41` 报错，仍未修复。游戏内按键效果待最终确认。
- Intel Mac 和其他系统尚未完成实测。universal 只表示启动器与按键组件含两种架构。
- App 仅有临时签名，尚无 Developer ID 签名或 Apple 公证；下载后的首次打开流程仍需另一台 Mac 验证。可能需要在 macOS「隐私与安全性」中允许打开。

这是预览版，不承诺所有地图、模组和联机模式稳定。
